# 直击产妇水中分娩全过程，生娃就是这么简单

> 更新时间：2026-09-19 (UTC+8)

水中分娩作为全新的顺产方式，有不少产妇都经历过，在国外尤其是因为，每年大约有2%的孕妇选择此种发生，而我国虽然案例并不多，但也有人成功体验过，比如谢依霖以及台湾明星Ella，下面跟随孕多多网的脚步，带你直击水中分娩全过程。

明星谢依霖尝试水中分娩

**水中分娩初体验——全过程分享**

在2015年1月份，浙江省公立医院公布了首例水中分娩孕妇成功顺产，27岁的张女士家住在七堡附近水中分娩的计划她一早就想好了，在怀孕期间就和老公商量并得到支持，最后在医护人员的共同努力下有惊无险的成功诞下男宝宝一枚！

张女士在分娩池产下男婴

**一、产前紧张的准备**

在怀孕33周左右，张女士一早就到杭州市妇产科医院咨询预约，非常幸运的是她成了浙江省公立医院首位尝试水中分娩的产妇，“刚到医院预约的时候，医生就一再强调，想要水中分娩，除了自身身体条件外，最关键是宝宝的体重不能过重”张女士说。

因此直到预产期到来前她都在控制饮食，吃的比较清淡，都会适当运动，散步、快走半小时左右，原本的预产期是1月16日，但是没想到的是宝宝会提前发动。

在1月6日凌晨，张女士已经睡下了，突然被一阵腹痛惊醒，到卫生间一看，发现见红了，紧接着就是频繁的宫缩，张女士在丈夫的陪同下赶到杭州市妇产科医院，挂了急诊，一检查宫口已经开了3厘米，此时已经疼的忍不住，紧紧掐着丈夫的手臂。

**二、产前身体评估**

但想要水中分娩条件就是胎儿不能太大，随后胎儿不能太大，分娩池就安置在这个产房里面，之后妇产科中心护士为张女士做了相关评估，“张女士怀孕期间产检一切正常，体重也控制得很好，胎儿的大小及胎位都很适合水中分娩”。

产前评估确保安全

**三、水中生产全过程**

早上11点左右，张女士的宫口已经开了6cm可以下水了，在医护人员的搀扶下，张女士进入分娩池，她的丈夫全程在一旁陪着她，为她加油鼓劲。

“一下水，水的温热就让我感觉到放松，没有之前那么痛了，也容易发力”张女士回忆到，“阵痛来的是时候会觉得腰酸，助产士就让我试着变换体位，不要总是躺着，侧躺和坐起来可以缓解疼痛，加快产程”。

直到中午12点40分张女士的宫颈全部开了，进入了第二产程，在陈红护士长和助产护士的引导下，张女士也积极配合她们，孩子出生的时间13点16分，体重6.5斤，是个男宝宝！就这样过了半小时左右，张女士成功诞下了小宝宝，全程有喊过一声疼，产道没有经历侧切，只有轻微的擦伤，出血量不超过150ml。

**四、分娩后感受**

张女士回忆到“当看到宝宝从水里出来，医护人员把他放在我身上的时候，真的觉得非常感动，我当妈妈了！”，她的丈夫也觉得不可思议，“我太太其实是很怕痛的人，胆子也比较小，凌晨开始她就痛得一直没睡，但是下了水以后一声疼都没喊过”。
